# Money Meter

<a href="https://reality-realms.github.io/money-meter-app/install.html"><img src="https://reality-realms.github.io/money-meter-app/download-button.png" alt="Download the app" width="320"></a>

A small app that shows playtime and money for the Family Meter, with charts.
It has no data of its own: after you add your own GitHub key (it stays on your
device), it reads the numbers from a private repo.

Open it: https://reality-realms.github.io/money-meter-app/
On an iPad: open the link in Safari, tap Share, then **Add to Home Screen**.
